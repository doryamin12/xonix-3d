# Xonix 3D

משחק תלת-מימדי בהשראת הקלאסיקה **Xonix**: שולטים בחללית שחותכת שטחים מתוך מסך פתוח וסוגרת אותם חזרה לקיר כדי לכבוש אותם, תוך הימנעות מכדורים קופצים. כיבשו 80% מהשטח כדי לעבור שלב — 20 שלבים, קושי עולה.

**שחקו עכשיו:** https://doryamin12.github.io/xonix-3d/

## תכונות

- תצוגה תלת-מימדית עילית (top-down) עם Three.js — קירות, שביל ושטח פנוי בגבהים שונים, צללים רכים, חלקיקים זוהרים, ואפקט זוהר (bloom) סלקטיבי על החללית והכדורים בלבד.
- גרפיקה משודרגת: צינור צבע HDR ליניארי עם ACES, החלקת קצוות (MSAA), קווי ניאון על גבולות קירות כבושים, שמי ערפילית וכוכבים, חללית מפורטת עם להבת מנוע ומגן זוהר, כדורים עם ליבה זוהרת.
- תחושת משחק: שטח כבוש "מתרומם" בגל מנקודת הסגירה, רעידת מצלמה, טבעות הדף, ניקוד צף, רגע קפאון והילוך איטי במוות, התראת סכנה כשכדור מתקרב לשביל, פתיח ושלב-הושלם חגיגי.
- ממשק חדש: HUD בסגנון ניאון (לבבות חיים, פס כיבוש עם סמן 80%, טבעות טיימר לפאוור-אפים), מסכים עם אנימציות כניסה וטבלת שיאים עם מדליות.
- 20 שלבים עם עקומת קושי עולה (יותר כדורים, מהירים יותר) **וגיוון פריסה** - מ-שלב 3 ואילך נוספים מכשולי קיר קבועים כך שכל שלב נראה שונה, לא רק קשה יותר.
- 4 פאוור-אפים רנדומליים: ⚡ מהירות, 🛡 מגן זמני, ❄ הקפאת כדורים, ❤ חיים נוסף.
- **תפריט השהיה** (`Esc`/`P` או כפתור ⏸) שמקפיא את המשחק לגמרי, כולל טיימרים של פאוור-אפים.
- שם שחקן וטבלת שיאים מקומית נשמרים בדפדפן בין הפעלות (`localStorage`).
- קובץ `index.html` יחיד — בלי build step, בלי תלויות מותקנות.

## שליטה

חצים או `WASD` לתנועה, `Space` להתחלה/אישור, `Esc`/`P` להשהיה.

## הרצה מקומית

הקובץ טוען את Three.js מ-CDN (ES modules), כך שדפדפנים חוסמים ES module imports מ-`file://`. יש להריץ שרת סטטי מקומי:

```bash
python -m http.server 8000
```

ואז לפתוח `http://localhost:8000/index.html`.

## פריסה

מתארח דרך GitHub Pages ישירות מענף `master` (תיקיית root) - כל `push` ל-`master` מתעדכן אוטומטית תוך דקה-שתיים. **הדפדפן שומר cache אגרסיבי** (`Cache-Control: max-age=600`) - אחרי כל עדכון יש לרענן עם `Ctrl+Shift+R` כדי לראות את הגרסה החדשה.
