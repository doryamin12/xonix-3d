# Xonix 3D

משחק תלת-מימדי בהשראת הקלאסיקה **Xonix**: שולטים בחללית שחותכת שטחים מתוך מסך פתוח וסוגרת אותם חזרה לקיר כדי לכבוש אותם, תוך הימנעות מכדורים קופצים. כיבשו 80% מהשטח כדי לעבור שלב — 20 שלבים, קושי עולה.

**שחקו עכשיו:** https://doryamin12.github.io/xonix-3d/

## תכונות

- תצוגה תלת-מימדית עילית (top-down) עם Three.js — קירות, שביל ושטח פנוי בגבהים שונים, צללים רכים ואפקט זוהר (bloom) על החללית והכדורים.
- 20 שלבים עם עקומת קושי עולה (יותר כדורים, מהירים יותר).
- 4 פאוור-אפים רנדומליים: ⚡ מהירות, 🛡 מגן זמני, ❄ הקפאת כדורים, ❤ חיים נוסף.
- שם שחקן וטבלת שיאים מקומית נשמרים בדפדפן בין הפעלות (`localStorage`).
- קובץ `index.html` יחיד — בלי build step, בלי תלויות מותקנות.

## שליטה

חצים או `WASD` לתנועה, `Space` להתחלה/אישור.

## הרצה מקומית

הקובץ טוען את Three.js מ-CDN (ES modules), כך שדפדפנים חוסמים ES module imports מ-`file://`. יש להריץ שרת סטטי מקומי:

```bash
python -m http.server 8000
```

ואז לפתוח `http://localhost:8000/index.html`.

## פריסה

מתארח דרך GitHub Pages ישירות מענף `master` (תיקיית root) - כל `push` ל-`master` מתעדכן אוטומטית תוך דקה-שתיים. **הדפדפן שומר cache אגרסיבי** (`Cache-Control: max-age=600`) - אחרי כל עדכון יש לרענן עם `Ctrl+Shift+R` כדי לראות את הגרסה החדשה.
